# 多平台 Markdown 排版工作台 · 设计约定

面向中文内容运营的桌面工具。工作台的第一职责是让人看清「源稿 → 六平台成稿 → 复制」的状态，任何装饰都让位给这个任务。

## 1. 视觉基调

暖纸底 + 墨蓝单一强调色，来自印刷物的秩序感，但界面控件全部使用标准 Web 组件形态：这是工具，不是一张纸。

- 页面底色是米白（`--bg`），卡片与面板用象牙色（`--surface`）抬起一档；不使用纯白与纯黑。
- 只有一种彩色：墨蓝（`--accent`）。用于主操作、当前平台、焦点环、链接。可见表面上占比 ≤ 5%。
- 状态色（警告琥珀、失败砖红、通过森绿）只在确实承载语义时出现，且始终同时给出文字，不靠颜色单独传达。
- 深度只有两级：1px 描边（`--elev-ring`）与极轻投影（`--elev-raised`）。没有重投影、没有玻璃拟态。

## 2. 字体与字号

**一处明确的偏离：** 参考体系让无衬线等于衬线，因为它的产出是印刷文档；本产品是操作界面，控件文字必须一眼可读。因此：

- 界面控件、标签、按钮、状态文字使用中文无衬线栈（`--font-ui`），14px 基准。
- 工作台主标题和分区标题继续使用中文衬线栈（`--font-serif`）。新排版成稿的预览标题和正文优先使用微软雅黑，缺失时用系统相近字体；代码保持等宽字体。
- 代码、路径、字符数使用等宽栈（`--font-mono`），带 CJK 回退，避免方框。
- 字号阶梯：12 / 13 / 14 / 16 / 20 / 28。正文行高 1.55，标题 1.25，控件 1.4。
- 标题不加字距技巧性的负值；中文正文 `letter-spacing: 0.01em` 即可。

## 3. 版式

1440×900 是主视口。三段式：

1. **顶栏（56px）**：产品名、源稿状态（未排版 / 已排版 / 已过期）、主操作「一键排版」。
2. **工作区（左右两栏）**：左侧 源稿（最小 380px，可收缩），右侧 预览（自适应，最小 520px）。两栏之间是 1px 可调分隔线，命中区 12px，悬停、拖动、键盘焦点使用墨蓝反馈；不用卡片包裹整块。
3. **平台栏**：位于预览上方，六个平台的横向切换，公众号在首位并默认选中；每个标签显示平台短名与文章类型。

间距基数 4px；面板内边距 16/20/24；区块之间 24；相关控件之间 8。

## 4. 组件与状态

| 组件 | 约定 |
| --- | --- |
| 主按钮 | 墨蓝底 + 象牙色文字，8px 圆角，36px 高，`--elev-ring-accent` 描边 |
| 次按钮 | 暖砂底 + 深暖文字，1px 描边 |
| 幽灵按钮 | 透明底 + 墨蓝描边，用于「打开平台」 |
| 排版模板 | 当前平台有可复制正文时，在编辑操作组之后显示低强调的「模板 · 当前版式」。窄成稿栏简写为「模板」，保留完整可访问名称。原生非模态浮层显示同稿排版样张：桌面三列、窄屏两列，选中项有墨蓝描边、勾选及「当前」。只有模板产出改变风格，应用外壳保持暖纸底和墨蓝控件。 |
| 外部发布入口 | 成稿操作栏右侧的低强调文字按钮，配下箭头，默认收起。展开为贴近按钮右边缘的竖排外链浮层（下方空间不足时向上翻），不占成稿空间；三条链接各有外链图标，不属于六平台标签，也不改变「打开平台」的目标。窄栏随操作换行；常规模式始终可用，专注编辑隐藏，退出后恢复为收起 |
| 平台标签 | 文字标签，2px 底部指示条；选中态用墨蓝文字与指示条，不用胶囊 |
| 状态标记 | 小方块 2px 圆角 + 12px 文字，颜色与文字同时表达状态 |
| 兼容性清单 | 展开式列表，每项一行：位置 + 现象 + 处理方式；`blocker` 项前置实心标记 |
| 发布预检 | 与画布同宽的暖纸折叠条，放在预览滚动区上方。未排版、过期、未发现线索用中性文字；发现风险或无法检查用琥珀提示，自动展开。编辑时只保留需要注意的状态，优先保障正文空间。每项给出成稿位置、原句和建议；条目过多时单独滚动。官方规则来源另折叠，标注正文或入口。既有墨蓝焦点环可用于键盘路径。 |
| 预览画布 | 象牙色纸面，1px 描边，28px 内边距，宽度随平台模拟（公众号 677px） |

必须实现的状态：空稿引导、排版中（按钮 loading，预览保留旧结果并标注）、单平台失败（该标签标红，其它平台照常）、输出过期（顶栏提示 + 复制按钮禁用并说明原因）、复制失败（给出可全选的手动复制文本域）。无警告时不渲染兼容性清单；排版成功只在顶栏的状态标记中显示，不在成稿上方重复提示。

六个平台共享独立于工作台的排版模板，并保留各自的结构兼容规则。默认「观点蓝调」以居中主标题、576px 最大版心和墨蓝章节层级建立编辑刊物的阅读节奏。公众号正文 18px/2，纯文字二级标题使用居中的墨蓝渐变章节签和实色托底；含链接等行内格式的章节用浅蓝底。三级标题和顶层独占一段的纯文字加粗仍用浅蓝标签，无序列表沿用空心圆和细引导线。头条、搜狐和腾讯使用浅蓝底章节与细线；百家与知乎使用墨蓝字和下划细线，不依赖底色。其余五个平台将 17px/1.9 直接内联到普通段落和列表项，用元素本身的标题、引用、列表、链接语义承载阅读层次，即使外层样式被移除也可读。标题单独复制，其他模板不改。

## 5. 交互

- 键盘：`Tab` 依次到源稿、平台标签、操作按钮；平台标签支持左右方向键切换；`Ctrl/Cmd + Enter` 触发一键排版。焦点环 2px，墨蓝色，偏移 2px。
- 左侧「导入源稿」保留文件导入、首次粘贴、原稿标题查看和原稿引用图片的配对；导入或首次成功排版后，原稿文本只读，不显示格式工具。右侧排版成功后在「复制正文」旁提供「编辑正文」与次级「专注编辑」；编辑时在操作栏下方、正文滚动区之外显示格式工具。标题、文字样式、链接和图片、块结构分组排列，窄栏换行。按钮图标沿用既有 1.5px 线宽、中文可访问名称和墨蓝焦点环。
- 工具栏中标题之后是字体与字号组。字体使用原生下拉（微软雅黑、黑体、宋体、楷体）；字号使用带 px 单位的原生下拉，把常用字号与其他字号分组，覆盖 12–72 的全部整数。先选中文字；没有正文选区时提示如何操作，不改变正文。两个下拉显示光标位置或选区中一致的值；混合字体、混合字号分别回退到「字体」「字号」。两项只修改当前成稿，不改变模板预设或工作台字体。
- 右侧编辑态在画布上方显示原生「当前平台标题」输入框，复用现有字段、标签和焦点环。标题、正文及插图只影响当前平台，不回写原稿；当前平台有改动就显示撤销操作。成稿粘贴和选图共用校验，读取与错误提示靠近工具。
- 分隔线支持键盘左右 24px、Enter 或双击复位。专注模式隐藏源稿与平台标签，顶部保留平台名、复制正文、退出按钮、格式工具和当前平台改动反馈；Esc 先关闭链接子交互，再退出专注。进出都复用正文 DOM。
- 模板用同一段中文样稿对比小标题、段落、引用和分隔，样张与实际成稿走同一渲染器；样张不进入剪贴板。打开后 Tab 可遍历、Enter 应用，Esc 关闭并回到入口。每个平台独立选择，重新排版沿用。换版成功立即更新当前平台并关闭；失败留在浮层说明重试办法。正文编辑中仍可查看样张，选项禁用并提示完成编辑；手动改过正文时禁止换版并说明原因；只改标题时允许换版，专注编辑不显示入口。
- 复制成功用 2 秒的轻提示，不用模态框。
- 动效只有一处：排版时预览画布 120ms 的不透明度过渡；`prefers-reduced-motion` 下取消。
- 所有失败提示写明原因与下一步，不写「出错了」。

## 6. 响应式与可达性

- ≥ 1280px：双栏，源稿默认占 38%，两栏最小 380/520px。900–1279px：双栏，源稿默认占 36%，两栏最小 320/480px。＜ 900px：源稿在上、成稿在下，隐藏调宽手柄，不产生页面横向滚动。桌面源稿输入框的最小高度随视口增至 240–440px。
- 正文编辑画布随可用宽度扩展（双栏 1040px 封顶、专注 1200px 封顶），独立滚动；表格与代码在块内溢出。专注时隐藏全局顶栏；普通编辑时无警告的兼容性清单让位给正文，有警告时仍可展开，平台声明随正文滚动。只读预览和复制样式保持平台原宽度。
- 正文与占位文字对比度 ≥ 4.5:1，大字 ≥ 3:1。
- 图标使用统一 1.5px 描边的内联 SVG；不用 emoji 或 Unicode 符号代替图标。

## 7. 不要做

- 不做渐变文字、彩色光晕、玻璃模糊、卡片嵌套卡片。
- 不用左侧彩色竖条装饰警告块；用底色 + 前置标记。
- 不用纯白页面底、纯黑文字、冷灰（slate 系）。
- 不用圆胶囊包裹平台切换；标签就是标签。
